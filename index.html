Get Confirmation ID via IID

Submit an Installation ID (IID) to retrieve the corresponding Confirmation ID (CID).

GET CIDMS API
The IID should be a long numeric string. Enter it below without dashes.
Paste the full IID. Dashes will be automatically removed.

Check IID Status

Verify whether an Installation ID has already been used or is available.

GET Status Check
Uses the justforcheck=1 flag to query status without retrieving a CID.
Response

Detect IID from Image + Get CID

Upload an image containing an IID. The system will OCR-detect the IID and return both the detected IID and the Confirmation ID.

POST Image → IID + CID
Converts your image to Base64 and sends it for processing. Supported formats: PNG, JPG, BMP, GIF.
📤
Click to upload or drag & drop
PNG, JPG, BMP, GIF — Max 3 MB
Response

Detect IID from Image

POST Image → IID Only
OCR-only: extracts the IID text from the uploaded image.

PIDMS Key Checker

Check the status and details of product keys (PID keys).

GET Key Checker
Enter one or more product keys, one per line. The API checks each key and returns its status.
Keys are separated by newlines. Maximum 50 keys per request recommended.
Response

Get Key Description

Retrieve the product description for keys without full status checking.

GET Description Lookup
Faster than full check. Returns product name and edition info.
Response

Redeem Keys

Attempt to redeem product keys via the REDEEMMS API.

GET Key Redemption
Enter keys to redeem. The API will process redemption and return results.
Response

Office 365 Account Checker

Check the status of Microsoft 365 accounts.

GET Account Checker
Enter accounts in email:password format, one per line.
Format: email:password — one account per line.
Response
